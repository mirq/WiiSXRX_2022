# WiiStation ENV: variables.
# One line each: group | name | default | what it does.
# This file is compiled into WiiStationGUI (mkvars.py -> wsx_vars.h) and
# shipped as WiiStation-Vars.txt. Settings in wiistation.cfg (Core,
# gpuPlugin, ...) can also be given as WSX_<Key>; the launcher passes those
# as arguments, so they are not listed here.

Display | WSX_WIDTH | 640 | Display width in pixels. GlesGpu assumes 640x480 for a few game fixes: change only to test.
Display | WSX_HEIGHT | 480 | Display height in pixels (see WSX_WIDTH).
Display | WSX_WINDOW | 0 | 1: run in a window on the Workbench instead of on a screen of its own. Same as the launcher's "Workbench window" box.
Display | WSX_VSYNC | 0 | 1: wait for the display's vertical blank at every present. No tearing, but frames can be lost. Same as "Wait for vsync".
Display | WSX_SHOWFPS | 0 | 1: show the emulation's frames a second on screen (60 is full speed for NTSC, 50 for PAL). Same as "Show FPS".
Display | WSX_BILINEAR | 1 | 0: no filtering of the software renderers' frame. The Radeon renderer follows the "Bilinear filter" box instead.
Display | WSX_DRAWCLIP | 1 | 0: do not clip drawing to the game's drawing area. The clip hides what games draw outside it (Tekken 3's menu needs it).
Display | WSX_MODEUP | 1 | 0: after a display mode change, do not upload the displayed VRAM again. R-Type Delta's logo screen needs the upload.
Display | WSX_MOV565 | 0 | 1: send movie frames to MiniGL as 16-bit 565 instead of 32-bit BGRA (the old way).
Display | WSX_CLOCK | tb | sys: time with GetSysTimePPC instead of the PowerPC time base.

Sound/Pads | WSX_AHI_MIXRATE | 44100 | AHI mixing rate in Hz. 22050 halves the 68k's sound work. Same as the launcher's Sound setting.
Sound/Pads | WSX_JOYPORTS | 0 | 1: read the joystick ports (joystick or CD32 pad) once a frame. Off by default: each read is a ~5 ms trip to the 68k. The keyboard always works.
Sound/Pads | WSX_VLC | 1 | Movie (MDEC) bitstream decoder: 1 = in C (fast), 0 = the game's own code on the dynarec, 2 = both, counting differences in the log (diagnosis).

CPU speed | WSX_NOIDLE | 0 | 1: never skip the game's idle loops. Slower; try it (and WSX_NOGATE) first when a game hangs or acts differently on one path.
CPU speed | WSX_NOGATE | 0 | 1: switch off the event gate (the dynarec checks for events after every block). Slower; for games that act strangely.
CPU speed | WSX_IDLECD | 0 | 1: skip idle loops even while the CD reads data. Faster loading, but R-Type Delta lost graphics and crashed with it.
CPU speed | WSX_FASTMEM | 1 | 0: every dynarec load and store goes through C. Much slower; to find memory bugs.
CPU speed | WSX_DISPATCH | 1 | 0: translated blocks return through recRun instead of the dispatcher stub (A/B test).
CPU speed | WSX_LINK | 1 | 0: no direct block linking; every jump goes back to the dispatcher (A/B test).
CPU speed | WSX_DELAYFAST | 1 | 0: every load in a branch delay slot takes the slow check (as before; fights 58 -> 56 fps).
CPU speed | WSX_KEEPREGS | 1 | 0: inline memory accesses give up all scratch registers (A/B test).
CPU speed | WSX_OUTLINE | 1 | 0: memory access slow paths stay inline. Bigger code; the 7410's 32 KB instruction cache is the limit.
CPU speed | WSX_ALTIVEC | 1 | 0: do not use the AltiVec routines on a G4 (7400/7410).
CPU speed | WSX_MASKGATE | 1 | 0: a raised but masked interrupt keeps the event gate open (the old behaviour).
CPU speed | WSX_HYB | - | lo-hi (hex PSX addresses): blocks starting in that range run on the interpreter. To find code the dynarec translates wrongly.
CPU speed | WSX_CYCLE0 | 0 | Start value of the PSX cycle counter (e.g. 0xf0000000, near its wrap): to test code that breaks at the wrap.

Renderer | WSX_LANES | 1 | 0: no second draw lane. With it, Silent Hill's ground draws in two state runs instead of hundreds (54 -> 60 fps).
Renderer | WSX_GLFLAT | 0 | 1: draw through MiniGL's screen-space MGL_FLATTRIANGLES instead of its transformed (TCL) path.
Renderer | WSX_TCLARRAY | 1 | 0: transformed path through glBegin/glEnd instead of vertex arrays.
Renderer | WSX_GLBATCH | 1 | 0: one glBegin per primitive on the transformed path (A/B test).
Renderer | WSX_GLARRAY | 1 | 0: do not send screen-space draws as one triangle list (GL_MGL_flat_triangles).
Renderer | WSX_ZALWAYS | 1 | 0: depth test off while the PSX mask bit is not checked. Silent Hill's trees go black without it.
Renderer | WSX_SOFTFILL | 1 | 0: full-screen clears are not copied into GlesGpu's own VRAM copy.
Renderer | WSX_UNSYNC | 1 | 0: texture cache uploads wait for the GPU to finish first.
Renderer | WSX_GLDEFER | 1 | 0: texture atlas planes are uploaded at once instead of deferred and merged.
Renderer | WSX_DEFERMERGE | 1 | 0: each deferred upload rectangle goes up on its own (one MiniGL call each, ~65 us) instead of merged.
Renderer | WSX_DEFERSLACK | 512 | Extra texels a merged upload rectangle may take in to join two rectangles.
Renderer | WSX_ONEPASS | 1 | 0: PSX blend mode 1 draws in two passes instead of one (alpha scale).
Renderer | WSX_ATLAS | 1 | 0: no texture atlas (each texture page a MiniGL texture of its own).
Renderer | WSX_ATLASCELLS | 16 | Use fewer cells of the 2048x512 texture atlas (tests).
Renderer | WSX_SORTTEX | auto | Fix GlesGpu's texture cache at n pages. By default it starts at 16 and grows to 64 when it keeps filling up.
Renderer | WSX_TEXQUAR | 1 | 0: freed texture space can be reused at once instead of at the next vsync (R-Type Delta's palette cycling slows down).
Renderer | WSX_PADUP | 1 | 0: textures get planes of their exact size instead of 256x256 planes (R-Type Delta made ~1000 textures).
Renderer | WSX_UNTEXMERGE | 0 | 1: draw untextured primitives inside a textured batch of the same blend (untested).
Renderer | WSX_GPUPAL | 0 | 1: look up 4/8-bit palettes on the GPU. Experimental: some sprites get wrong colours.
Renderer | WSX_GL_NOSCALE | 0 | 1: do not use MiniGL's 2x colour scale (PSX colours above 0x80 then clamp).
Renderer | WSX_GL_NORSUB | 0 | 1: do not use subtractive blending (PSX mode B-F becomes B x (1-F)).
Renderer | WSX_GL_NOASCALE | 0 | 1: do not use MiniGL's alpha scale.

CD | WSX_CDASYNC | 1 | 0: read the disc image synchronously.
CD | WSX_CDRUN | 32 | Most sectors read at once ahead of the game (4..32).
CD | WSX_CDSTALL | 1 | 0: deliver a sector even while the game has not acknowledged the last CD interrupt.
CD | WSX_CDVERIFY | 0 | 1: check every asynchronous read against a plain one (diagnosis).

Run control | WSX_AUTOFRAMES | - | n: run n PSX frames, log the frame rate and quit (benchmarks). Set for one run only.
Run control | WSX_LOADSTATE | - | n: load the save state (the F7 one) at frame n: the quick way back to a scene.
Run control | WSX_SAVESTATE | - | n: save the state at frame n.
Run control | WSX_QUIT | - | 1: quit the running emulator (from another Shell). The launcher clears it before every run.
Run control | WSX_LOGASYNC | 1 | 0: write the log with fopen at every flush (20-28 ms every 2 s) instead of an async DOS packet.

Diagnosis | WSX_SHOT | - | n: save present n into T:shot.ppm (exact colours).
Diagnosis | WSX_SHOTAT | - | n: save the first present after PSX frame n into T:shot.ppm.
Diagnosis | WSX_PRIMPROBE | - | n: log every primitive of PSX frame n ([prim] lines). F8 does the same for the frame after next.
Diagnosis | WSX_GPPROBE | - | all: log every palette-path primitive of frame 290 (with WSX_GPUPAL 1).
Diagnosis | WSX_GPDEBUG | 0 | 1: the GPU palette path draws which column/slot it hit instead of colours.
Diagnosis | WSX_GPMASK | 15 | Which primitives take the GPU palette path: 1 4-bit, 2 8-bit, 4 opaque, 8 semi-transparent (sum).
Diagnosis | WSX_TEXLOG | 0 | n: log the first n texture cache uploads after frame 1500.
Diagnosis | WSX_IMGLOG | 0 | n: log n image (VRAM) transfers, from frame WSX_IMGFROM on.
Diagnosis | WSX_IMGFROM | 0 | The frame WSX_IMGLOG starts at.
Diagnosis | WSX_DMAWATCH | - | addr (hex): log DMAs into RAM over that address, and the word there once a frame.
Diagnosis | WSX_WWATCH | - | addr (hex): log stores to that PSX address (exact pc with WSX_FASTMEM 0).
Diagnosis | WSX_PCWATCH | - | pc (hex): log stores made by the instruction at that pc.
Diagnosis | WSX_BDUMP | - | pc (hex): dump the translated code of the block at that pc into the log.
Diagnosis | WSX_CRASHTEST | 0 | 1: make a deliberate bad store at start, to test the crash report.

Profiling | WSX_PMC | 0 | 1: program the 7410's performance counters and log [pmc] lines (cycles, cache misses per stage).
Profiling | WSX_PMCSEL | 1,5,5,2 | Events for PMC1-4 with WSX_PMC 1 (default: cycles, L1 I-misses, L1 D-misses, instructions).
Profiling | WSX_PMCPROF | - | cycles (e.g. 40000): sampling profiler; writes T:pcsamp.bin. Needs WSX_PMC 1.
Profiling | WSX_PMCPROF_AT | 400 | The present the sampler starts at (999999: wait for F9).
Profiling | WSX_GLBENCH | 0 | 1: time MiniGL's immediate mode at startup ([glbench] lines).
Profiling | WSX_GTEBENCH | 0 | 1: time the busiest GTE operations at startup ([gtebench] lines).

MiniGL | MGLPPC_TCL6 | 1 | 0: send 7-dword TCL vertices (with W). 1 drops W: less data over the Zorro bus (fights ~49 -> ~51 fps).
MiniGL | MGLPPC_TCL5 | 1 | 0: keep Z in vertices when the depth test is off (5 dwords without it).
MiniGL | MGLPPC_CPEMIT | 1 | 1: the PPC builds the GPU command stream. Needed for the blending and colour-scale extensions: keep 1.
MiniGL | MGLPPC_CPPRESENT | 1 | 1: the back buffer keeps its pixels after a present (some games draw over the last frame): keep 1.
MiniGL | MGLPPC_NOALTIVEC | 1 | 0: let MiniGL use AltiVec.
MiniGL | MGLPPC_HOSTPRI | -1 | Priority of the 68k host process. Keep -1: at 1 it starved the system and the machine needed a reset.
MiniGL | MGLPPC_HOST | - | Path of minigl_ppc_host when it is not in PROGDIR: or LIBS:.
MiniGL | MGLPPC_NOHOSTSTART | 0 | 1: MiniGL does not start minigl_ppc_host itself (start it by hand first).
MiniGL | MGLPPC_NOSTATEMEMO | 0 | 1: no state memo; every state change emits the full register set (Silent Hill 54 -> 52 fps).
MiniGL | MGLPPC_SEGREAD | 0 | 1: read VRAM back after each draw's vertices (as before; Silent Hill 54.6 -> 50.5 fps).
MiniGL | MGLPPC_NODIRECTTCL | 0 | 1: stage TCL vertices instead of writing them straight into the segment.
MiniGL | MGLPPC_NOINPLACE | 0 | 1: no in-place texture pool updates.
MiniGL | MGLPPC_POOLSLOTS | - | Number of texture pool slots.
MiniGL | MGLPPC_POOLSYNCROW | 0 | 1: texture pool syncs per row (test).
MiniGL | MGLPPC_NOTCLFAST | 0 | 1: no fast TCL draw path.
MiniGL | MGLPPC_NOTCL7 | 0 | 1: no 7-dword TCL path.
